UVa 10055 · 讀到檔案結尾、取絕對差

兩軍兵力差

Hashmat the Brave Warrior

每組給兩個軍隊人數，可能先給大數，也可能先給小數。你的程式要輸出兩者相差多少；人數一樣就印 0。

輸入
每行兩個非負整數 a b，上限是 2³²。沒有測資組數，也沒有結束標記；讀到 EOF（檔案結尾）為止。
輸出
每組印一行非負的差值，不必印題號或任何說明文字。

01解題步驟

  1. 用 while (cin >> a >> b) 同時讀兩個值。只有成功讀到完整一組，才會進入迴圈。
  2. 比較 a 和 b，用較大的減去較小的。程式裡的 a >= b ? a - b : b - a 意思就是「條件成立用左邊，否則用右邊」。
  3. 用 long long 存兩個人數及差值。2³² 是 4,294,967,296，超過常見 32 位元 int 的正數上限。

02跟著算一次

先比較，再相減

第一個數第二個數選哪個式子輸出
141014 − 104
101414 − 104
123123123 − 1230

範例輸入

10 12
14 10

範例輸出

2
4

03容易錯在哪

  • 10 14 和 14 10 都應印 4；只寫 a - b 會在其中一組印出負數。
  • 0 0 也是一筆資料，應印 0。EOF 指的是沒有更多輸入，不是讀到零。
C++ 參考解
#include <iostream>
using namespace std;

int main() {
    long long a, b;
    while (cin >> a >> b) {
        cout << (a >= b ? a - b : b - a) << '\n';
    }
}

UVa 11150 · 從換瓶流程找出公式

空瓶換可樂

Cola

先買 N 瓶可樂，喝完後可用 3 個空瓶換 1 瓶新的。你可以借空瓶，但最後必須還清。問包含原本買的在內，最多總共能喝幾瓶。

輸入
每行一個整數 N，1 ≤ N ≤ 200；讀到 EOF。
輸出
每行印一個整數，表示最多喝到的總瓶數。

01解題步驟

  1. 原本買的 N 瓶全部喝完後，手上有 N 個空瓶。
  2. 每換 1 瓶要交 3 個空瓶，喝完又得到 1 個空瓶，所以一輪實際消耗 2 個。只要空瓶足夠，就一直換。
  3. 如果最後剛好剩 2 個，借 1 個湊成 3 個再換。喝完後剩下的 1 個還給對方，借瓶就還清了。
  4. 因此最多多喝 N / 2 瓶，總數是 N + N / 2。這裡兩邊都是整數，9 / 2 的結果是 4。

02跟著算一次

買 8 瓶時，最後可以喝到 12 瓶

動作手上的空瓶累計喝掉
先喝完買來的 8 瓶88
連換 3 次，每次淨少 2 個空瓶8 → 6 → 4 → 211
借 1 個再換，喝完把 1 個還掉2 → 3 → 0（還清後）12

範例輸入

8
9

範例輸出

12
13

03容易錯在哪

  • 只剩 1 個空瓶時，借 2 個換完只會拿回 1 個，還不清，不能再多喝。
  • 答案要加上最開始買的 N 瓶；不能只印換到的瓶數。
C++ 參考解
#include <iostream>
using namespace std;

int main() {
    int n;
    while (cin >> n) cout << n + n / 2 << '\n';
}

UVa 11332 · 用 % 10 拆出個位數

反覆加總各位數

Summing Digits

把一個數字的每一位相加，再對新的總和做同一件事，直到結果只剩一位數。例如 9875 的第一輪結果是 9＋8＋7＋5＝29，還要繼續算。

輸入
每行一個正整數 n，最大 2,000,000,000。讀到 0 就結束。
輸出
對每組資料印一行最後的個位數。結束標記 0 不輸出。

01解題步驟

  1. 當 n >= 10，代表還有兩位以上，需要再做一輪加總。每輪先設 total = 0。
  2. 用 n % 10 取得最右一位；例如 9875 % 10 得到 5。再用 n /= 10 去掉那一位，9875 變成 987。
  3. 一直拆到 n == 0，再把 total 放回 n 開下一輪。這就是為什麼要用另一個變數累加：n 正在被拆掉。
  4. 剩下 1 到 9 時停止，直接印出結果。輸入一開始就是一位數，也直接印。

02跟著算一次

9875 經過三輪後變成 2

輪次這輪的數把各位相加下一輪的數
198755＋7＋8＋929
2299＋211
3111＋12

範例輸入

11
47
1234567892
0

範例輸出

2
2
2

03容易錯在哪

  • 每進入新一輪要重設 total。例如上一輪累加到 29，下一輪要從 0 開始加 9 和 2。
  • 拆位時從右到左，但加法的順序不影響總和。
C++ 參考解
#include <iostream>
using namespace std;

int main() {
    long long n;
    while (cin >> n && n != 0) {
        while (n >= 10) {
            int total = 0;
            while (n > 0) {
                total += n % 10;
                n /= 10;
            }
            n = total;
        }
        cout << n << '\n';
    }
}

UVa 10783 · 包含端點、每組歸零

區間內的奇數和

Odd Sum

給你一個從 a 到 b 的整數區間，把其中所有奇數相加。左右端點也是區間的一部分。

輸入
第一個整數 T 是測資組數（1 ≤ T ≤ 100）。每組有 a 和 b 兩個整數，0 ≤ a ≤ b ≤ 100，原題分兩行給。
輸出
每組印 Case k: S，k 從 1 起算，S 是奇數總和。冒號後有一個空格。

01解題步驟

  1. 先讀 T，再用外層迴圈逐組讀 a 和 b。每組的總和要重新設成 0。
  2. 用內層迴圈從 a 走到 b，條件寫 x <= b，這樣才會檢查右端點。
  3. 用 x % 2 != 0 判斷奇數；只有奇數加進總和。最後印出測資編號與結果。

02跟著算一次

從 3 加到 7，只加奇數

x要不要加目前總和
3加 33
4跳過3
5加 58
6跳過8
7加 715

範例輸入

2
1
5
3
5

範例輸出

Case 1: 9
Case 2: 8

03容易錯在哪

  • 如果 a == b，仍要檢查一次。例：[7, 7] 的答案是 7，[8, 8] 是 0。
  • 不要把「奇數和」寫成「奇數有幾個」。例如 3、5、7 要加成 15。
C++ 參考解
#include <iostream>
using namespace std;

int main() {
    int T;
    if (!(cin >> T)) return 0;
    for (int k = 1; k <= T; ++k) {
        int a, b, total = 0;
        cin >> a >> b;
        for (int x = a; x <= b; ++x) {
            if (x % 2 != 0) total += x;
        }
        cout << "Case " << k << ": " << total << '\n';
    }
}

上一題反覆加總各位數下一題二進位有幾個 1

UVa 10931 · 除以 2 取餘數、字元轉換

二進位有幾個 1

Parity

每組給一個十進位整數 n。要印出它的二進位表示，以及其中有幾個 1。題目的輸出格式有「(mod 2)」，但數字欄要放完整的 1 的個數。

輸入
每行一個 1 到 2,147,483,647 的整數。讀到 0 結束。
輸出
用 The parity of B is P (mod 2). 印一行，B 是無前導零的二進位字串，P 是其中 1 的個數。句點也要印。

01解題步驟

  1. 用 bit = n % 2 取得目前最右邊的二進位位元。因為餘數只會是 0 或 1，可直接用 ones += bit 來計數。
  2. '0' 是字元 0，跟整數 0 不一樣。char('0' + bit) 把數字 0 或 1 變成可以放進字串的 '0' 或 '1'。
  3. 餘數先拿到的是低位，所以下一個餘數要加到字串前面：binary = char('0' + bit) + binary。例如已有 1，下一個拿到 0，就變成 01。
  4. 再用 n /= 2 去掉這個位元。重複到 n == 0，這組字串就組完了。

02跟著算一次

用 21 走一遍轉換

本輪的 nn % 2插到前面後目前 1 的個數n / 2
2111110
1000115
5110122
20010121
111010130

範例輸入

10
21
0

範例輸出

The parity of 1010 is 2 (mod 2).
The parity of 10101 is 3 (mod 2).

03容易錯在哪

  • 最後要印 ones，不要先算 ones % 2。21 的輸出要印 3，即使 3 除以 2 的餘數是 1。
  • 每組資料要清空 binary，並把 ones 重設成 0。
C++ 參考解
#include <iostream>
#include <string>
using namespace std;

int main() {
    long long n;
    while (cin >> n && n != 0) {
        string binary;
        int ones = 0;
        while (n > 0) {
            int bit = n % 2;
            ones += bit;
            binary = char('0' + bit) + binary;
            n /= 2;
        }
        cout << "The parity of " << binary << " is " << ones
             << " (mod 2).\n";
    }
}

上一題區間內的奇數和下一題判斷 11 的倍數

UVa 10929 · 超長字串、交錯加減

判斷 11 的倍數

You can say 11

判斷一個十進位正整數是否能被 11 整除。它可能長達 1,000 位，所以先用字串存原本的數，再用各位數計算。

輸入
每行一個最多 1,000 位的正整數；單獨的 0 表示結束。
輸出
可以整除就印 N is a multiple of 11.，否則印 N is not a multiple of 11.。N 要原樣輸出。

01解題步驟

  1. 從字串左邊開始，把第 0、2、4… 格的數字加起來，第 1、3、5… 格的數字減掉。n[i] - '0' 把字元轉回數字。
  2. 為什麼可行？10 和 −1 對 11 同餘，因為兩者相差 11。10 的次方對 11 就會在 1 和 −1 之間交替，所以展開每一位後，只要交錯加減就能判斷整除。
  3. 左邊或右邊起算可能讓整個結果變號，但不影響它能不能被 11 整除。最後只檢查 sum % 11 == 0。

02跟著算一次

56958 的交錯總和是 11

位置 i這一位這步怎麼算目前 sum
050 ＋ 55
165 − 6−1
29−1 ＋ 98
358 − 53
483 ＋ 811

範例輸入

112233
112234
0

範例輸出

112233 is a multiple of 11.
112234 is not a multiple of 11.

03容易錯在哪

  • 可以直接取餘數的是「各位數算出的小總和」。原數最多 1,000 位，不能先轉 int 或 long long 再做 % 11。
  • 總和可能是 0 或負數；例如 −11 仍然能被 11 整除。別寫成 sum == 11。
C++ 參考解
#include <iostream>
#include <string>
using namespace std;

int main() {
    string n;
    while (cin >> n && n != "0") {
        int sum = 0;
        for (size_t i = 0; i < n.size(); ++i) {
            int digit = n[i] - '0';
            sum += (i % 2 == 0) ? digit : -digit;
        }
        cout << n << (sum % 11 == 0 ? " is a multiple of 11.\n"
                                   : " is not a multiple of 11.\n");
    }
}

上一題二進位有幾個 1下一題9 的倍數與 9-degree

UVa 10922 · 分清楚 sum、temp 與輪次

9 的倍數與 9-degree

2 the 9s

先判斷原數是不是 9 的倍數。若是，反覆把各位數相加，數到結果變成 9 為止，這個輪數就是 9-degree。依題目定義，原數就是 9 時，degree 是 1。

輸入
每行一個最多 1,000 位的正整數；單獨的 0 表示結束。
輸出
不是 9 的倍數就印 N is not a multiple of 9.；是的話印 N is a multiple of 9 and has 9-degree D.。保留原本的 N。

01解題步驟

  1. 用 string n 存原數，再逐一用 c - '0' 加進 sum。1,000 位的第一次總和最多 9,000，所以這個總和用 int 就夠。
  2. 因為 10 除以 9 餘 1，每一位的位權都不影響對 9 的餘數。若 sum % 9 != 0，原數就不是 9 的倍數。
  3. 第一次把字串加總已算一輪，因此 degree = 1。如果 sum 仍有兩位以上，就用 sum % 10 取位數，加進新一輪的 temp，再把 sum 除以 10。
  4. 拆完時 sum 暫時會變 0，這時才執行 sum = temp，用新總和換掉舊數，再做一次 ++degree。

02跟著算一次

21 個 9，第一輪就已經算進 degree

第幾輪加總前這輪計算加總後degree
121 個 921 × 91891
21899 ＋ 8 ＋ 1182
3188 ＋ 193

範例輸入

18
9999
20
0

範例輸出

18 is a multiple of 9 and has 9-degree 1.
9999 is a multiple of 9 and has 9-degree 2.
20 is not a multiple of 9.

03容易錯在哪

  • 以 189 為例，sum 會走 189 → 18 → 1 → 0；temp 同時走 0 → 9 → 17 → 18。最後把 18 寫回 sum。
  • 一次完整的加總才增加一次 degree；拆出三個位數，不是增加三次。每輪也要重新把 temp 設為 0。
C++ 參考解
#include <iostream>
#include <string>
using namespace std;

int main() {
    string n;
    while (cin >> n && n != "0") {
        int sum = 0;
        for (char c : n) sum += c - '0';
        if (sum % 9 != 0) {
            cout << n << " is not a multiple of 9.\n";
            continue;
        }
        int degree = 1;
        while (sum >= 10) {
            int temp = 0;
            while (sum > 0) {
                temp += sum % 10;
                sum /= 10;
            }
            sum = temp;
            ++degree;
        }
        cout << n << " is a multiple of 9 and has 9-degree "
             << degree << ".\n";
    }
}

上一題判斷 11 的倍數下一題TeX 引號轉換

UVa 272 · 逐字元讀入、跨行保留狀態

TeX 引號轉換

TEX Quotes

把文字裡普通的雙引號換成 TeX 格式：第一個雙引號換成兩個反引號（grave accents），第二個換成兩個單引號（apostrophes），後面照此交替。

輸入
輸入是多行文字，讀到 EOF。同一對雙引號可能跨行。
輸出
只有雙引號要換。其他字元、空格、標點、換行都原樣輸出。

01解題步驟

  1. 用 cin.get(c) 一次讀一個字元。跟 cin >> c 不同，這種寫法會保留空格和換行。
  2. 設 opening = true，意思是「下一個雙引號是開頭」。碰到雙引號時，按 opening 選擇要輸出哪種符號。
  3. 每處理完一個雙引號才做 opening = !opening。一般字元直接輸出，不改狀態。

02跟著算一次

跨行時，不會把關閉引號當成新的一對

讀到的事件輸出什麼下一個雙引號
第一個雙引號兩個反引號關閉
普通文字或換行照原樣輸出仍是關閉
下一個雙引號兩個單引號開頭

範例輸入

She said "hello".
"Bye!"

範例輸出

She said ``hello''.
``Bye!''

03容易錯在哪

  • 狀態要跨行保存。讀到換行不能把 opening 重設成 true。
  • 程式用 char(96) 表示反引號；右邊的兩個單引號與兩個反引號是不同字元。
C++ 參考解
#include <iostream>
using namespace std;

int main() {
    bool opening = true;
    char c;
    while (cin.get(c)) {
        if (c == '"') {
            if (opening) cout << char(96) << char(96);
            else cout << "''";
            opening = !opening;
        } else {
            cout << c;
        }
    }
}

UVa 100 · 算每個起點的長度，再取最大

3n＋1 序列

The 3n + 1 Problem

從任一正整數 n 開始：偶數除以 2，奇數變成 3n＋1，直到變成 1。給你兩個端點，找區間中「序列長度」（cycle length）最大的長度。

輸入
每行兩個正整數 i j，都小於 1,000,000，順序可能顛倒。讀到 EOF。
輸出
每組印 i j maxLength。前兩個數一定要用輸入時的原順序。

01解題步驟

  1. 單獨看一個起點。n == 1 時長度是 1；其他時候，長度等於「目前這一項」加上下一個數的長度。
  2. 區間迴圈從 min(i, j) 走到 max(i, j)（含端點）。每算完一個長度，就更新最大值。
  3. 不同起點可能走到同一段。例如 6 的序列後面會走到 5，就可以沿用 5 已經算好的長度。參考解用 memo 記錄小於 1,000,000 的長度，這叫記憶化（memoization）。
  4. 用 long long 存中間的 n。即使起點不到 1,000,000，做 3 * n + 1 後也可能變得很大。

02跟著算一次

輸入 6 4，算區間 [4, 6]

起點序列長度
44 → 2 → 13
55 → 16 → 8 → 4 → 2 → 16
66 → 3 → 10 → 5 → 16 → 8 → 4 → 2 → 19

範例輸入

1 10
100 200

範例輸出

1 10 20
100 200 125

03容易錯在哪

  • 長度數的是序列裡的項數，開頭與最後的 1 都要算。例如 4 → 2 → 1 長度是 3。
  • 調整順序只為了好跑迴圈；輸出 6 4 時，仍要印 6 4 9。
C++ 參考解
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

vector<int> memo(1000000);

int cycle(long long n) {
    if (n < 1000000 && memo[n]) return memo[n];
    long long next = n % 2 ? 3 * n + 1 : n / 2;
    int length = 1 + cycle(next);
    if (n < 1000000) memo[n] = length;
    return length;
}

int main() {
    memo[1] = 1;
    int i, j;
    while (cin >> i >> j) {
        int best = 0;
        for (int n = min(i, j); n <= max(i, j); ++n) {
            best = max(best, cycle(n));
        }
        cout << i << ' ' << j << ' ' << best << '\n';
    }
}

火車車廂交換

Train Swapping

車廂要按號碼從小排到大，但一次只能交換相鄰兩節。題目問最少需要交換幾次。

輸入
先讀測資組數 T。每組給車廂數 L（0 ≤ L ≤ 50），再給 1 到 L 的一個排列。
輸出
每組印 Optimal train swapping takes S swaps.，S 是最少次數。原格式即使 S 是 1 也用 swaps。

01解題步驟

  1. 定義逆序對（inversion）：前面一節的號碼，比後面那一節大。它們不必相鄰。
  2. 交換相鄰且順序顛倒的一對，會剛好消掉一個逆序對。其他車廂都在這兩節的同一邊，所以它們的相對先後不受影響。
  3. 排好後逆序對數目是 0。只交換顛倒的相鄰車廂就能一次少一對，因此初始逆序對有幾個，最少就要換幾次。
  4. 用兩層迴圈枚舉 i < j。只要 a[i] > a[j]，答案就加 1。L ≤ 50，直接枚舉就夠。

02跟著算一次

3 1 4 2 只要三次相鄰交換

次數交換哪一對交換後
0起始排列3 1 4 2

範例輸入

3

4

範例輸出

Optimal train swapping takes 6 swaps.

03容易錯在哪

  • 逆序對不必相鄰；例如 3 1 4 2 裡的 3 和 2 也算一對。
  • 沒有車廂或本來就排好，答案是 0。
C++ 參考解
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int cases;
    if (!(cin >> cases)) return 0;
    while (cases--) {
        int n;
        cin >> n;
        vector<int> a(n);
        for (int &x : a) cin >> x;
        int inversions = 0;
        for (int i = 0; i < n; ++i)
            for (int j = i + 1; j < n; ++j)
                if (a[i] > a[j]) ++inversions;
        cout << "Optimal train swapping takes " << inversions
             << " swaps.\n";
    }
}

孟加拉數字表示法

Bangla Numbers

把十進位數拆成孟加拉數字單位。從大到小是 kuti = 10,000,000、lakh = 100,000、hajar = 1,000、shata = 100。數字夠大時，kuti 可以重複出現。

輸入
每行一個非負整數，最大 999,999,999,999,999；讀到 EOF。0 是一筆有效資料。
輸出
每組先印右對齊、寬度 4 的測資編號和句點，再印拆出的數字與單位，項目以空格隔開。

01解題步驟

  1. 用 long long 存數字。拿一個單位做整數除法，商是這個單位有幾份，餘數留給下一個較小的單位。
  2. 先處理 kuti：如果 n >= 10000000，先用同一個函式印商，再印 kuti，最後處理餘數。這就是遞迴（recursion），用同一個拆數規則處理更小的商。
  3. 接著依序處理 lakh、hajar、shata。商是 0 就跳過；小於 100 的尾數若非零，直接印。

UVa 10035 · 個位數、傳遞 carry

直式加法進位次數

Primary Arithmetic

模擬兩個非負整數的直式加法。每一欄的和到 10 或以上，就會向左進位一次。題目要的是總進位次數。

輸入
每行兩個少於 10 位的非負整數。只有 0 0 同時出現才結束。
輸出
零次印 No carry operation.；一次印 1 carry operation.；兩次以上印 C carry operations.。

01解題步驟

  1. 每組先設 carry = 0 和 count = 0。用 a % 10 和 b % 10 取得目前兩個個位數。
  2. 當前欄的總和是「兩個位數＋右邊傳來的 carry」。總和至少是 10，就把新 carry 設為 1，並把 count 加 1；否則新 carry 是 0。
  3. 把兩個數都除以 10 去掉處理完的那一位。只要任一個數仍有位數，就要繼續；比較短的數缺位時，它的個位數就是 0。

02跟著算一次

95＋7 有兩次進位

欄位取到的兩個位數右邊傳來本欄加總累計次數
個位5、7012，向左進位1
十位9、0110，向左進位2

範例輸入

123 456
555 555
123 594
0 0

範例輸出

No carry operation.
3 carry operations.
1 carry operation.

03容易錯在哪

  • 95 + 7 的十位是 9＋0＋1，最後的 1 是個位傳來的進位，不能漏掉。
  • 最高位向左進位已在該欄被計數；新出現的最高位數字 1 不會再多算一次。單數、複數與句點照題目印。
C++ 參考解
#include <iostream>
using namespace std;

int main() {
    unsigned long long a, b;
    while (cin >> a >> b && (a != 0 || b != 0)) {
        int carry = 0, count = 0;
        while (a > 0 || b > 0) {
            int column = (a % 10) + (b % 10) + carry;
            carry = (column >= 10);
            count += carry;
            a /= 10;
            b /= 10;
        }
        if (count == 0) cout << "No carry operation.\n";
        else if (count == 1) cout << "1 carry operation.\n";
        else cout << count << " carry operations.\n";
    }
}
英文題意與輸入輸出

Output: For zero carries print No carry operation. For exactly one print 1 carry operation. For C > 1 print C carry operations. Preserve the punctuation.

Back to High School Physics

已知粒子做等加速度運動，在時間 t 的速度是 v。求從時間 0 到時間 2t 的位移，位移有正負方向。
