UVa 10055

Hashmat the Brave Warrior

Class exercise

Given the sizes of two armies in either order, find the absolute difference between them.

Input

Read pairs of nonnegative integers until end of file. Each value is at most 2^32.

Output

Print one difference per pair. Equal army sizes produce 0.

Key idea: Subtract the smaller army size from the larger one.

  1. Use a 64-bit integer type: 2^32 exceeds the usual signed int limit.
  2. Read both values together until end of file. Subtract the smaller from the larger.

Watch for: Use long long. An input value can be 2^32, and equal sizes give zero.

Sample output

View C++ reference solution
#include <iostream>
using namespace std;

int main() {
    long long a, b;
    while (cin >> a >> b) {
        cout << (a >= b ? a - b : b - a) << '\n';
    }
}

UVa 11150

Cola

CPE 2010-12-23

You buy N bottles of cola. The store trades three empty bottles for one full bottle. You may borrow empties if you repay them. Find the maximum number of bottles you can drink.

Input

Read one integer N per line until end of file (1 ≤ N ≤ 200).

Output

For each N, print the maximum total, including the bottles you bought.

Key idea: Every extra drink costs two empty bottles overall. The total is N + N / 2 with integer division.

  1. Drinking the original N bottles gives N empty bottles.
  2. Each trade followed by drinking costs two empties overall: you hand in three and get one empty back.
  3. If two empties remain, borrow one for a final trade and return the empty you get back. This allows exactly floor(N / 2) extra drinks.

Watch for: At two empty bottles, borrowing one makes a final trade possible. Return the empty bottle from that drink. With one empty bottle, a final trade would leave you unable to repay two borrowed empties.

#include <iostream>
using namespace std;

    int n;
    while (cin >> n) cout << n + n / 2 << '\n';
}

UVa 11332

Summing Digits

CPE 2022-10-18

Replace a positive integer with the sum of its decimal digits. Repeat until one digit remains.

Input

Read one integer N per line, with 1 ≤ N ≤ 2,000,000,000 for each case. A 0 ends the input.

Output

For each case, print the remaining digit on its own line. Do not process the final 0.

Key idea: Add all the digits, then repeat with the sum until it has only one digit.

  1. If the value is already below 10, it is the answer.
  2. Use n % 10 to read the rightmost digit and n /= 10 to remove it.
  3. Accumulate the digits in a fresh total, replace n, and repeat.

Watch for: Start each new digit sum at zero. An input of 0 ends the input and produces no output.

Worked example

View C++ reference solution
#include <iostream>
using namespace std;

int main() {
    long long n;
    while (cin >> n && n != 0) {
        while (n >= 10) {
            int total = 0;
            while (n > 0) {
                total += n % 10;
                n /= 10;
            }
            n = total;
        }
        cout << n << '\n';
    }
}

UVa 10783

Odd Sum

CPE 2014-05-27

Write a program that adds all odd integers in the inclusive interval from a to b. Include an endpoint if it is odd.

Input

The first line contains T, the number of cases (1 ≤ T ≤ 100). Each case supplies a and b on separate lines, with 0 ≤ a ≤ b ≤ 100.

Output

Print one line per case in the form Case k: S, where k starts at 1 and S is the sum. Print 0 for an interval with no odd numbers.

Key idea: Scan the inclusive interval and add only odd values.

  1. Read the case count first. Reset total to zero for each interval.
  2. Loop from a through b, including b. The test x % 2 != 0 selects odd values.
  3. Print the case label, a space after the colon, and the total.

Watch for: Include both endpoints. Reset the sum for each case and start the case number at 1.

#include <iostream>
using namespace std;

int main() {
    int T;
    if (!(cin >> T)) return 0;
    for (int k = 1; k <= T; ++k) {
        int a, b, total = 0;
        cin >> a >> b;
        for (int x = a; x <= b; ++x) {
            if (x % 2 != 0) total += x;
        }
        cout << "Case " << k << ": " << total << '\n';
    }
}

UVa 10931

Parity

CPE 2022-12-13

Convert each input integer to binary and count the 1 bits. The required sentence shows the full count before the literal text (mod 2), even when the count is greater than 1.

Input

Read one integer per line. Each value to process is between 1 and 2,147,483,647. Stop at 0 and produce no line for it.

Output

For a binary representation B with P ones, print The parity of B is P (mod 2). Use no leading zeros in B.

Key idea: Divide by 2 repeatedly. Put each remainder at the front of the binary string and count the ones.

  1. The remainder n % 2 is the next bit. Add that numeric bit to the count.
  2. Convert the bit to a character with char('0' + bit). Prepend it because the remainders arrive from right to left.
  3. Use integer division n /= 2 to remove the processed bit.

Watch for: In char('0' + bit), '0' is the character for the digit zero. Adding 1 produces the character code for '1'. For input 21, the binary result is 10101 and the printed count is 3.

Worked example

1110102

Sample input

10
21
0

Sample output

The parity of 1010 is 2 (mod 2).
The parity of 10101 is 3 (mod 2).
View C++ reference solution
#include <iostream>
#include <string>
using namespace std;

int main() {
    long long n;
    while (cin >> n && n != 0) {
        string binary;
        int ones = 0;
        while (n > 0) {
            int bit = n % 2;
            ones += bit;
            binary = char('0' + bit) + binary;
            n /= 2;
        }
        cout << "The parity of " << binary << " is " << ones
             << " (mod 2).\n";
    }
}

UVa 10929

You can say 11

CPE 2011-12-20

Determine whether each positive decimal integer is divisible by 11. An input value can be too large for an integer type.

Input

Read one positive decimal integer per line, up to 1,000 digits. A line containing 0 ends input.

Output

For a multiple, print N is a multiple of 11. Otherwise print N is not a multiple of 11. Use the original input for N.

Key idea: Alternate plus and minus signs over the digits. The number is divisible by 11 exactly when that sum is.

  1. Keep the original number in a string.
  2. Convert each digit with n[i] - '0'. Add digits at even indices and subtract digits at odd indices.
  3. Because 10 is congruent to −1 modulo 11, the alternating sum is divisible by 11 exactly when the original value is.

Watch for: Keep the input as a string because it can have 1,000 digits. The alternating sum can be negative or zero; sum % 11 == 0 still works.

Worked example

IndexDigitRunning sum
05+5 = 5
165 − 6 = −1
29−1 + 9 = 8
358 − 5 = 3
483 + 8 = 11

Sample input

112233
112234
0

Sample output

112233 is a multiple of 11.
112234 is not a multiple of 11.
View C++ reference solution
#include <iostream>
#include <string>
using namespace std;

int main() {
    string n;
    while (cin >> n && n != "0") {
        int sum = 0;
        for (size_t i = 0; i < n.size(); ++i) {
            int digit = n[i] - '0';
            sum += (i % 2 == 0) ? digit : -digit;
        }
        cout << n << (sum % 11 == 0 ? " is a multiple of 11.\n"
                                   : " is not a multiple of 11.\n");
    }
}

UVa 10922

2 the 9s

CPE 2015-03-24

Determine whether a positive decimal integer is divisible by 9. For a multiple of 9, repeatedly replace it with the sum of its decimal digits and report how many rounds are needed to reach 9. The degree of 9 itself is 1.

Input

Read one positive integer per line, with at most 1,000 digits. A line containing 0 ends the input and is not processed.

Output

For a multiple, print N is a multiple of 9 and has 9-degree D. Otherwise print N is not a multiple of 9. Replace N with the original input and D with the degree.

Key idea: Add the digits once to test divisibility by 9. If it is a multiple, count the digit-sum rounds until reaching 9.

  1. Read the large number as a string. The first digit sum is at most 9,000, so an int can hold it. Subtract '0' from each digit character.
  2. Test sum % 9. If the remainder is nonzero, the original number is not divisible by 9.
  3. Count the first digit sum as round 1. Each time sum still has multiple digits, start temp at zero, collect its digits into temp, and then replace sum with temp and increment degree.

Watch for: When sum starts at 189, temp starts at 0. Taking the digits 9, 8, and 1 makes temp go 0 → 9 → 17 → 18 while sum shrinks to 0. Copy temp back into sum and increase degree once.

Worked example

RoundValue beforeDigits addedValue after
121 copies of 921 × 9189
21899 + 8 + 118
3188 + 19

Sample input

18
9999
20
0

Sample output

18 is a multiple of 9 and has 9-degree 1.
9999 is a multiple of 9 and has 9-degree 2.
20 is not a multiple of 9.
View C++ reference solution
#include <iostream>
#include <string>
using namespace std;

int main() {
    string n;
    while (cin >> n && n != "0") {
        int sum = 0;
        for (char c : n) sum += c - '0';
        if (sum % 9 != 0) {
            cout << n << " is not a multiple of 9.\n";
            continue;
        }
        int degree = 1;
        while (sum >= 10) {
            int temp = 0;
            while (sum > 0) {
                temp += sum % 10;
                sum /= 10;
            }
            sum = temp;
            ++degree;
        }
        cout << n << " is a multiple of 9 and has 9-degree "
             << degree << ".\n";
    }
}

UVa 272

TEX Quotes

CPE 2011-05-25

Convert plain double quotation marks to TeX-style pairs. An opening quote becomes two grave accents; a closing quote becomes two apostrophes.

Input

Read the complete text until end of file. Quotation pairs may span lines.

Output

Copy every other character unchanged, including line breaks and spaces. Alternate opening and closing replacements across the entire input.

Key idea: Replace each double quote according to whether it opens or closes a pair.

  1. Use cin.get(c) to read every character, including whitespace.
  2. Keep one boolean that tells whether the next double quote is opening.
  3. After replacing a quote, flip the boolean. Do not reset it at a newline.

Watch for: A quotation can span multiple lines. Keep the same opening/closing flag when you read a newline.

Worked example

First quote``Closing
Line breakUnchangedClosing
Next quote''Opening

Sample input

She said "hello".
"Bye!"

Sample output

``Bye!''
View C++ reference solution
#include <iostream>
using namespace std;

int main() {
    bool opening = true;
    char c;
    while (cin.get(c)) {
        if (c == '"') {
            if (opening) cout << char(96) << char(96);
            else cout << "''";
            opening = !opening;
        } else {
            cout << c;
        }
    }
}

UVa 100

The 3n + 1 Problem

CPE 2025-09-30

Start at n. Until reaching 1, replace an odd n with 3n + 1 and an even n with n / 2. The cycle length counts all terms, including the start and 1. Find the maximum cycle length over each inclusive interval.

Input

Read pairs i and j until end of file (0 < i, j < 1,000,000). The endpoints can arrive in either order.

Output

Print i and j in their original order, then the maximum cycle length. Separate the three numbers with one space.

Key idea: Compute the cycle length of every number in the interval and keep the maximum.

  1. Set the length of 1 to 1. For other values, the length is one plus the length of the next value.
  2. Use long long for intermediate values and cache known lengths below 1,000,000.
  3. Normalize the endpoints only for the loop. Print the original i and j.

Watch for: You may need to swap the endpoints to loop over the range. Print them in the same order as the input. Count the final 1.

Worked example

StartSequenceLength
111
44 → 2 → 13
55 → 16 → 8 → 4 → 2 → 16

Sample input

1 10
100 200

Sample output

1 10 20
100 200 125
View C++ reference solution
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

vector<int> memo(1000000);

int cycle(long long n) {
    if (n < 1000000 && memo[n]) return memo[n];
    long long next = n % 2 ? 3 * n + 1 : n / 2;
    int length = 1 + cycle(next);
    if (n < 1000000) memo[n] = length;
    return length;
}

int main() {
    memo[1] = 1;
    int i, j;
    while (cin >> i >> j) {
        int best = 0;
        for (int n = min(i, j); n <= max(i, j); ++n) {
            best = max(best, cycle(n));
        }
        cout << i << ' ' << j << ' ' << best << '\n';
    }
}

UVa 299

Train Swapping

CPE 2017-09-26

Sort the numbered train carriages using only swaps of adjacent carriages. Report the smallest possible number of swaps.

Input

Read the number of cases T. Each case gives a length L (0 ≤ L ≤ 50) followed by a permutation of 1 through L.

Output

Print Optimal train swapping takes S swaps. for every case, substituting the minimum swap count for S.

Key idea: The minimum number of adjacent swaps equals the number of out-of-order pairs.

  1. An inversion is an out-of-order pair: the earlier carriage has a larger number.
  2. Swapping an adjacent inverted pair removes exactly one inversion. Sorting this way uses exactly as many swaps as the original inversion count.
  3. With at most 50 carriages, two nested loops can count all inversions directly.

Watch for: Only adjacent swaps count. For [3, 1, 4, 2], the three inverted pairs require exactly three swaps.

Worked example

OrderInverted pairsMinimum swaps
3 1 4 2(3,1), (3,2), (4,2)3
1 2 3 4None0

Sample input

2
3
1 3 2
4
4 3 2 1

Sample output

Optimal train swapping takes 1 swaps.
Optimal train swapping takes 6 swaps.
View C++ reference solution
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int cases;
    if (!(cin >> cases)) return 0;
    while (cases--) {
        int n;
        cin >> n;
        vector<int> a(n);
        for (int &x : a) cin >> x;
        int inversions = 0;
        for (int i = 0; i < n; ++i)
            for (int j = i + 1; j < n; ++j)
                if (a[i] > a[j]) ++inversions;
        cout << "Optimal train swapping takes " << inversions
             << " swaps.\n";
    }
}

UVa 10101

Bangla Numbers

CPE 2018-12-18

Express each input using Bangla number units: kuti (10,000,000), lakh (100,000), hajar (1,000), and shata (100). A value can contain more than one kuti.

Input

Read nonnegative integers up to 999,999,999,999,999 until end of file. Zero is a normal case.

Output

For each input, print the 1-based case number right-aligned in a field of width four, then a period and the converted value. Put one space before each number or unit.

Key idea: Split the number by its largest Bangla unit. Format the part before kuti recursively.

  1. Use long long. For n ≥ 10,000,000, recursively format the quotient, then print kuti and process the remainder.
  2. For the smaller units, print a group only when it is nonzero.
  3. Use setw(4) for the case number. Print 0 for the whole input zero, but omit zero remainder groups.

Watch for: Keep the case number right-aligned in four columns. A value such as 10^14 produces two kuti units. Zero is a real input.

Worked example

10000000000000010,000,000 × 10,000,0001 kuti kuti

Sample input

0
23764

Sample output

   1. 0
   2. 23 hajar 7 shata 64
View C++ reference solution
#include <iomanip>
#include <iostream>
using namespace std;

void printBangla(long long n) {
    if (n >= 10000000) {
        printBangla(n / 10000000);
        cout << " kuti";
        n %= 10000000;
    }
    if (n >= 100000) {
        cout << ' ' << n / 100000 << " lakh";
        n %= 100000;
    }
    if (n >= 1000) {
        cout << ' ' << n / 1000 << " hajar";
        n %= 1000;
    }
    if (n >= 100) {
        cout << ' ' << n / 100 << " shata";
        n %= 100;
    }
    if (n != 0) cout << ' ' << n;
}

int main() {
    long long n;
    int k = 1;
    while (cin >> n) {
        cout << setw(4) << k++ << '.';
        if (n == 0) cout << " 0";
        else printBangla(n);
        cout << '\n';
    }
}

UVa 10035

Primary Arithmetic

CPE 2023-03-21

Count the carries that occur during ordinary decimal addition. Work from the units column toward the left, passing a carry of 1 to the next column whenever the current column totals 10 or more.

Input

Each line contains two nonnegative decimal integers of fewer than 10 digits. Stop when both numbers are 0. A single zero operand is valid.

Output

For zero carries print No carry operation. For exactly one print 1 carry operation. For C > 1 print C carry operations. Preserve the punctuation.

Key idea: Add one decimal column at a time, carrying a 1 into the next column when needed.

  1. Read the current digit of each operand with % 10. Add the carry from the column to the right.
  2. The new carry is 1 if the column sum is at least 10; otherwise it is 0. Count the new carry, then remove both processed digits with / 10.
  3. Use the singular output for one carry and the plural output for two or more.

Watch for: Use the exact output text for zero, one, and several carries. A line with just one zero operand is still a case.

Worked example

Column in 95 + 7Digit sumNew carryCount
Units5 + 7 + 0 = 1211
Tens9 + 0 + 1 = 1012

Sample input

123 456
555 555
123 594
0 0

Sample output

No carry operation.
3 carry operations.
1 carry operation.
View C++ reference solution
#include <iostream>
using namespace std;

int main() {
    unsigned long long a, b;
    while (cin >> a >> b && (a != 0 || b != 0)) {
        int carry = 0, count = 0;
        while (a > 0 || b > 0) {
            int column = (a % 10) + (b % 10) + carry;
            carry = (column >= 10);
            count += carry;
            a /= 10;
            b /= 10;
        }
        if (count == 0) cout << "No carry operation.\n";
        else if (count == 1) cout << "1 carry operation.\n";
        else cout << count << " carry operations.\n";
    }
}

CPE 2017-12-19

A particle moves with constant acceleration. Its velocity at time t is v. Determine its signed displacement from time 0 to time 2t.

Input

Read pairs v and t until end of file, where −100 ≤ v ≤ 100 and 0 ≤ t ≤ 200. A pair of zeros is a valid case.

Output

Print the displacement as a single integer for each input pair.

Key idea: Multiply the midpoint velocity v by the full time 2t.

  1. With constant acceleration, the velocity at the midpoint t equals the average velocity over the interval from 0 to 2t.
  2. Displacement equals average velocity times elapsed time, so calculate 2 * v * t.
  3. Process all pairs to EOF, including zero and negative values.

Watch for: The formula also works for a negative v or t = 0. Even 0 0 is a normal input line.

View C++ reference solution
#include <iostream>
using namespace std;

int main() {
    int v, t;
    while (cin >> v >> t) cout << 2 * v * t << '\n';
}
